# ΤΑΒΛΑΚΙ ΣΤΟ ΛΙΘΙ

Παραδοσιακό ελληνικό τάβλι σε offline HTML, με AI, προφίλ παίκτη και PWA εγκατάσταση.

## Νέες δυνατότητες

- AI με επίπεδα δυσκολίας: Εύκολο, Κανονικό και Δύσκολο
- Animation στα ζάρια και στις κινήσεις
- Web Audio ήχοι για ρίψη, κίνηση, χτύπημα και νίκη
- XP και achievements
- Προφίλ παίκτη με νίκες, ήττες και σερί
- Τοπικό leaderboard με `localStorage`
- Αυτόματη αποθήκευση και επαναφορά παρτίδας μετά από refresh
- Responsive mobile/touch UX
- PWA manifest και offline cache μέσω service worker
- Πόρτες, Πλακωτό και Φευγά

## Εκτέλεση

Άνοιξε το `index.html` σε browser ή χρησιμοποίησε το δημόσιο GitHub Pages site:

https://0ur910s-wq.github.io/tavlaki-sto-lithi/

> Σημείωση: το πραγματικό online multiplayer reconnect απαιτεί ξεχωριστό realtime server. Η τρέχουσα έκδοση προσφέρει offline session recovery μετά από refresh ή προσωρινή απώλεια σελίδας.
