# ΤΑΒΛΑΚΙ ΣΤΟ ΛΙΘΙ

Παραδοσιακό ελληνικό τάβλι σε offline HTML, με λειτουργία εναντίον AI ή για δύο παίκτες.

## Περιλαμβάνει

- Πόρτες, Πλακωτό και Φευγά
- Σειρά τριών αγώνων με σκορ
- Βελτιωμένο board με αισθητική ξύλου και τσόχας
- Επισήμανση διαθέσιμων κινήσεων και έξοδο πούλιων
- Responsive εμφάνιση για μικρότερες οθόνες

## Εκτέλεση

Άνοιξε το `index.html` σε browser ή φιλοξένησέ το ως στατικό GitHub Pages site.
